## 🚀 Bắt Đầu Cài Đặt (Getting Started)

Làm theo các bước dưới đây để thiết lập và chạy dự án ở môi trường cục bộ (Local Development).

### 1. Yêu cầu môi trường (Prerequisites)

- [Node.js](https://nodejs.org/) (phiên bản `>= 18.x`)
- [Git](https://git-scm.com/)
- Trình quản lý gói: `npm` hoặc `yarn` / `pnpm`

### 2. Cài đặt từng bước (Installation)

1. **Clone repository:**
   ```bash
   git clone https://github.com/[username]/[repo-name].git
   cd [repo-name]
   ```

2. **Cài đặt dependencies:**
   ```bash
   npm install
   ```

3. **Cấu hình biến môi trường:**
   Sao chép file `.env.example` thành `.env`:
   ```bash
   cp .env.example .env
   ```
   Sau đó mở `.env` và điền các thông số cần thiết (API URL, Port, Secret Key...).

4. **Khởi chạy ứng dụng:**
   ```bash
   npm run dev
   ```
   Mở trình duyệt và truy cập: `http://localhost:3000`
